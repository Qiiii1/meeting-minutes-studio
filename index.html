一个可以亲手体验的想法

会记把录音、原文、纪要与行动项放在一个工作台。当前是 GitHub Pages 上的开源交互原型。

现在可以

线下麦克风或线上双声源录音、讯飞实时转写、DeepSeek 自动整理、录音回听与下载，以及纪要编辑和 PDF 导出。

整理规则

内置 meeting-notes Skill 的摘要、要点、决策、行动项、下一步和待确认结构，并要求缺失信息不臆测。

音频会发送至讯飞，整理时会议原文会发送至 DeepSeek，均使用你自己的账号额度。密钥只在页面内存中保留。会议文字与录音保存在此浏览器，请及时下载备份。
